# Code of conduct

Readbook adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be kind, assume good faith, welcome newcomers, critique ideas rather than people,
and keep discussions focused on making Readbook better. Harassment, discrimination and
personal attacks are not tolerated in issues, pull requests or any other project space.

**Reporting.** If someone's behavior makes you uncomfortable, contact the maintainer
privately through GitHub (open a private security advisory with "Conduct" in the title if you
need a private channel). Reports are handled confidentially. The maintainer may remove
comments, close threads or block participants who break these rules.
